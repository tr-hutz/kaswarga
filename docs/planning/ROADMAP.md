# Roadmap

## Purpose

This document describes the long-term product roadmap for KasWarga.

It is intended to communicate the strategic direction of the project.

This document does NOT contain implementation tasks.

Detailed implementation work belongs in the project backlog.

---

# Current Status

Current Version:

v2.0.0

Status:

Release Candidate

---

# Guiding Principles

The roadmap follows these principles:

- Stability before new features.
- Backward compatibility whenever possible.
- Mobile-first user experience.
- Maintainable architecture.
- Security by default.
- Automation wherever possible.

---

# Product Vision

KasWarga aims to become a complete neighborhood management platform that is:

- Easy to use
- Transparent
- Secure
- Scalable
- Extensible

# Review Policy

The roadmap should be reviewed:

- Before every major release.
- After significant architecture changes.
- When project priorities change.
