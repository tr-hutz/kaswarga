# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2026-07-25

### Added

- New TailAdmin-based user interface.
- Generic DataTable with pagination and filtering.
- Theme System (Light / Dark / System).
- Full internationalization support.
- Activity Log improvements.
- Production-ready test infrastructure.

### Changed

- Migrated entire codebase to English.
- Migrated database schema to English.
- Upgraded to full TypeScript strict mode.
- Standardized UI component architecture.

### Fixed

- Drawer rendering issues.
- Ledger page title.
- Missing registration routes.
- Payment approval workflow.
- Various responsive layout issues.

### Security

- Removed development API endpoints.
- Removed hardcoded credentials.
- Strengthened Supabase access control.
